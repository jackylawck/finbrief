🔒 ISO 27001 & ISO 42001 Privacy-by-Design 治理架構

🔒 零數據留存 (Zero Data Retention / ZDR)

採用純 Session-Only 無狀態記憶體架構 (Stateless In-Memory Architecture)。上傳之財務報表數據僅用於當次計算，伺服器硬碟不保存任何原始檔案。
Files are processed strictly in RAM and never saved to server disks, meeting ISO 27001 data minimization requirements.

🔒 商業級金鑰隱蔽性 (BYOK Memory Protection)

在 BYOK 模式下，使用者輸入之 API Key 僅存於當前視窗的 Session State 中。用戶關閉分頁或瀏覽器後，金鑰即刻於記憶體中銷毀。
API keys in BYOK mode reside in session memory only and are immediately destroyed upon closing the browser tab.
