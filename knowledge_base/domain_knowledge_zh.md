# 財務報表分析核心指引 (HKFRS)

1. **資產負債表 (靜態快照)**
   - 核心恆等式：資產 = 負債 + 股東權益。
   - 評估重點：流動資產是否足以應付流動負債 (短期償債能力)，以及負債比例是否過高。若股東權益為負，需高度警示資不抵債風險。

2. **損益表 (動態成績單)**
   - 評估重點：不僅看純利，更要分析「毛利率」(反映核心業務定價能力與成本控制) 與「純利率」(反映整體盈利效率)。
   - 警示訊號：若營業額下跌但開支未相應減少，反映成本控制能力弱。

3. **現金流量表 (真金白銀流向)**
   - 核心觀念：有盈利不等於有現金。
   - 評估重點：經營活動現金流必須持續為正。若賬面盈利但經營現金流長期為負，可能存在收款困難 (應收帳款積壓) 或盈利質素偏低。融資現金流若為主要現金來源，代表依賴借貸，財務不穩健。
